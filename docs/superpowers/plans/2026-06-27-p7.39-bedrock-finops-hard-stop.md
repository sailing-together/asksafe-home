# P7.39 Bedrock FinOps Hard Stop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop Bedrock calls before they happen when anonymous, registered, or global AI usage quotas are exhausted.

**Architecture:** Add a server-side quota gate inside the Bedrock explanation helper, before prompt construction and model invocation. Use DynamoDB conditional updates against the existing events table for production counters, with dependency injection for deterministic unit tests. If quota storage is missing or unavailable while Bedrock is enabled, fail closed and fall back to deterministic rules.

**Tech Stack:** Next.js App Router, TypeScript, Node test runner, AWS SDK DynamoDB DocumentClient, existing AskSafe DynamoDB runtime config.
