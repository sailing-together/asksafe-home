> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a server API route that persists sanitized safety event metadata without storing raw user message text.

**Architecture:** Keep the Next.js route thin and place validation/response mapping in a focused server helper. The helper calls the existing DynamoDB persistence layer and returns safe HTTP-style responses for success, missing AWS config, invalid input, and write failure.

**Tech Stack:** Next.js App Router route handlers, TypeScript, Node test runner, existing DynamoDB persistence helpers.
